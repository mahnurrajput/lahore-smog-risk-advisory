========== 4. Enable the DVC merge driver and merge again ==========
$ git config merge.dvc.name DVC merge driver
$ git config merge.dvc.driver dvc git-hook merge-driver --ancestor %O --our %A --their %B
$ cat .gitattributes
# Use DVC's merge driver for .dvc files (setup: see "Resolving .dvc merge conflicts" in README)
*.dvc merge=dvc
$ git merge --no-edit demo/teammate-b -m demo: merge B into A
